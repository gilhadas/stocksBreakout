# Breakout Scanner Cron Jobs
# Add these to your crontab with: crontab -e
#
# IMPORTANT: All times are US Eastern (NYSE/NASDAQ market hours)
# TZ=America/New_York is set per-job so cron fires at the correct ET time
# regardless of the server's local timezone.
# Format: minute hour day month weekday command
#
# HEALTHCHECKS.IO SETUP (free remote monitoring):
# 1. Sign up at https://healthchecks.io (free: 20 checks)
# 2. Create checks: longterm, swing, daytrade, monitor, validate
# 3. Replace HC_UUID_xxx placeholders below with your real UUIDs
# 4. Install mobile app for push notifications on failures
# Ping format: curl -fsS -m 10 --retry 3 https://hc-ping.com/UUID
#
# S3 UPLOAD:
# upload_to_s3.py uploads the specific signal file just produced (--files)
# plus the portfolio directory and lists directory (--dirs scanner_output/portfolio scanner_output/lists).
# scanner_output/lists/ holds the premium/momentum watchlists and positions CSVs read by Streamlit.
# Log files (.log) are never uploaded — they stay local only.
# Upload logs: scanner_output/logs/cron_upload.log

# ============================================
# GLOBAL CONFIGURATION
# ============================================
